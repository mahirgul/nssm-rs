Robust Features for Mission-Critical Services

Everything you need to wrap, supervise, and stabilize long-running processes

Crash Throttling (AppThrottle)

Stops CPU spinning when an application crashes immediately upon startup. Exponential backoff delays restarts until the process demonstrates healthy uptime.

Log Rotation (AppRotate)

Redirect stdout and stderr to disk files. Automatically rotates logs when they exceed a configurable size (AppRotateBytes) or elapsed time.

Configurable Exit Actions

Define process exit behaviors: Restart automatically, Ignore, Exit, or execute clean self-termination.

Windows SCM & systemd

One tool for all environments. Installs directly as native Windows services via Windows Service Control Manager, or generates clean Linux systemd units.

Direct Execution (exec)

Supervise any command on the fly without installing a system service: nssm-rs exec node server.js --rotate.

Graceful Shutdown

Sends graceful SIGTERM / Ctrl+C signals first, allowing database connections to close, before escalating to SIGKILL only if the child process hangs.

Quick Installation

Build and run nssm-rs on Linux or Windows

Clone & Build with Cargo:
git clone https://github.com/mahirgul/nssm-rs.git && cd nssm-rs && cargo build --release
Install service with parameters:
./target/release/nssm-rs install MyService /usr/bin/python3 main.py
