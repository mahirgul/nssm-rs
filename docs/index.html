Engineered for Windows Reliability

Solves all common Windows Service wrapping pain points with modern Rust safety

Native Windows SCM Integration

Hooks directly into the Windows Service Control Manager. Visible in services.msc, controllable via sc.exe, PowerShell, or the Services GUI.

Crash Throttling (AppThrottle)

Prevents catastrophic 100% CPU lockups when a Windows service crashes immediately upon startup. Exponential backoff protects your server from reboot loops.

Automatic Log Rotation

Redirect console stdout/stderr to files with automatic size-based rotation (AppRotateBytes) without locking file handles on Windows.

Process Priority & Affinity

Configure Windows process priority class (Realtime, High, Normal, Idle) and pin background processes to specific CPU core affinity masks.

Extra Environment Variables

Inject custom environment variables into the service environment via AppEnvironmentExtra without polluting the global Windows System PATH.

Graceful Shutdown

Sends Windows Ctrl+C and WM_CLOSE events to allow applications to save state and clean up, with configurable timeout before forcing termination.
